D. APERSEPSI

Bayangkan kamu sedang membuat aplikasi data siswa. Program perlu mengetahui: Nama siswa, Kelas, Umur, Nilai, Jurusan.

Dugaan Cara Menyimpan Informasi dalam Program:
Kita dapat menggunakan variabel di JavaScript dengan menggunakan kata kunci let atau const, lalu mengisinya dengan nilai teks (string) menggunakan tanda petik atau angka (number) secara langsung.

E. AKTIVITAS 1 - MENGAMATI

let nama = "Budi";
let umur = 16;
let nilai = 85;
console.log(nama);
console.log(umur);
console.log(nilai);
Jawaban Pertanyaan:
  1. Apa yang ditampilkan pada Console? Budi, 16, dan 85.
  2. Apa fungsi nama, umur, dan nilai? Untuk menyimpan data nama, umur, dan nilai.
  3. Apa yang terjadi jika kode console.log(nama); dijalankan? Menyimpan variabel nama yaitu Budi.
  4. Apa yang dimaksud dengan variable? Tempat untuk menyimpan data agar dapat digunakan kembali dalam program.

F. AKTIVITAS 2 - MENGENAL VARIABLE

Mengenal struktur dasar penulisan variabel:

let nama = "Andi";

let = Membuat variabel | nama = Nama variabel | = = Memberikan nilai | "Andi" = Nilai yang disimpan.

J. AKTIVITAS 6 – MENGENAL let DAN const

K. Aktivitas 7 - Aturan Penamaan Variable

Aturan Utama Penamaan Variable JavaScript:
  • Boleh menggunakan huruf, angka, garis bawah (_), atau tanda dolar ($).
  • Tidak boleh diawali dengan angka (Contoh salah: 2nama).
  • Tidak boleh menggunakan spasi (Contoh salah: nama siswa).
  • Tidak boleh menggunakan karakter tanda hubung/strip (Contoh salah: nama-siswa).
  • bersifat Case-Sensitive (huruf besar dan kecil dibedakan). nama != Nama.

S. REFLEKSI & 3-2-1

3 Hal yang Dipelajari:
  1. Cara mendeklarasikan variabel menggunakan let dan const.
  2. Aturan penamaan variabel yang benar di JavaScript (tidak pakai spasi, tidak diawali angka).
  3. Menampilkan data ke konsol menggunakan console.log().

2 Hal yang Masih Membingungkan:
  1. Kapan waktu terbaik memilih jenis data tertentu secara efisien.
  2. Pesan error JavaScript yang kadang panjang di console browser.

1 Hal yang Ingin Dicoba:
  1. Membuat kalkulator sederhana menggunakan variabel.

T. KESIMPULAN

  • Variable adalah wadah atau tempat penampung untuk menyimpan data di dalam memori program.
  • let digunakan untuk mendeklarasikan variabel yang nilainya masih dapat berubah (bisa di-reassign).
  • const digunakan untuk mendeklarasikan variabel yang nilainya tetap dan tidak boleh diubah setelah diinisialisasi.
  • Untuk menampilkan isi variable ke Console kita dapat menggunakan console.log().
